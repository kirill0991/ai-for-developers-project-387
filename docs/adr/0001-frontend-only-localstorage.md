# Только фронтенд, без бэкенда, хранение в localStorage

> **Status:** superseded by ADR-0002

Сервис работает целиком на фронтенде: брони хранятся в `localStorage` браузера, серверной части нет. Это осознанный выбор для учебного MVP — стек проекта не включает бэкенд, а скоуп ограничен бронированием звонков и просмотром броней. Позже хранение можно вынести в API и БД, но на текущем этапе сервер только усложнил бы проект без пользы для целей обучения.
