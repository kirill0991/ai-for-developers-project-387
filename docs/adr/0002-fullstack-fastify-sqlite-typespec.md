# Full-stack: Fastify + SQLite, API-контракт TypeSpec

Проект переходит с фронтенд-only (ADR-0001) на full-stack: появляется бэкенд на Fastify с хранением в SQLite (`better-sqlite3`), а API описывается TypeSpec-контрактом, из которого генерируются OpenAPI, клиентский SDK (orval) и серверные артефакты (`@typespec/json-schema` → валидация и типизация маршрутов Fastify). Это нужно для выполнения требований курса: TypeSpec-контракт, покрывающий сценарии владельца и гостя, и генерация OpenAPI/SDK/серверных артефактов одной командой. ADR-0001 устаревает.
