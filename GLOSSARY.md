# Календарь звонков

Упрощённый сервис бронирования времени по мотивам Cal.com: владелец предлагает время для встреч, гость бронирует свободный слот.

## Language

**Владелец**:
Человек, чей календарь бронируют. Создаёт типы событий. В системе ровно один владелец.
_Avoid_: Хост, организатор, хозяин

**Гость**:
Человек, который бронирует слот. Не авторизуется, при брони указывает имя и email.
_Avoid_: Клиент, посетитель, пользователь

**Тип события**:
Категория встреч, которую создаёт владелец. Имеет название, описание и длительность в минутах.
_Avoid_: Вид брони, тип встречи, услуга

**Встреча**:
Единица бронирования — встреча переменной длительности (заданной типом события), которую гость бронирует у владельца.
_Avoid_: Звонок, событие, консультация

**Слот**:
Конкретный интервал времени длительностью типа события, доступный для бронирования.
_Avoid_: Интервал, окно, таймслот

**Бронь**:
Слот, зарезервированный гостем. Содержит имя и email гостя и ссылается на тип события.
_Avoid_: Запись, резервирование, заказ

**Расписание**:
Шаблон рабочих часов владельца (ежедневно 9:00–18:00), из которого генерируются слоты.
_Avoid_: Доступность, график, рабочие часы
